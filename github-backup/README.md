### Changing colors
All colors are defined as CSS variables at the top of the `<style>` block. Search for `:root {` to find them:

```css
:root {
  --sage: #2d5a3d;       /* Primary green */
  --sage2: #3d7a54;      /* Hover green */
  --gold: #c9a430;       /* Gold accent */
  --parchment: #faf7f2;  /* Background */
}
```

Change any hex value to update the color across the whole site instantly.
